## 📌 Sobre o Projeto

Este projeto consiste na criação de um **dashboard financeiro interativo no Microsoft Power BI**, desenvolvido a partir da base de dados Financials Sample.

O objetivo foi transformar os dados em informações visuais que permitam analisar o desempenho de vendas e lucratividade através de diferentes perspectivas, utilizando recursos de **visualização de dados, filtros, segmentadores, navegação e indicadores**.

O projeto foi desenvolvido como parte da Formação **Power BI Analyst da DIO**, buscando aplicar na prática os conceitos apresentados durante a formação e construir uma entrega que também pudesse compor meu portfólio de projetos em Data Analytics e Business Intelligence.

---

## 🎯 Objetivos

- Desenvolver um relatório financeiro interativo;
- Criar indicadores para acompanhamento dos principais resultados;
- Analisar o comportamento das vendas ao longo do tempo;
- Comparar vendas entre diferentes segmentos;
- Analisar o desempenho dos produtos;
- Identificar a distribuição das vendas por país;
- Criar uma segunda página dedicada à análise de lucro;
- Aplicar filtros e segmentadores para exploração dos dados;
- Implementar navegação entre as páginas do relatório;
- Desenvolver uma apresentação visual organizada e orientada à análise.

# 📊 Dashboard

## 1️⃣ Sales Report

A primeira página apresenta uma visão geral do desempenho de vendas.

### Principais indicadores

- **Total de Vendas**
- **Unidades Vendidas**
- **Total de Descontos**
- **Soma de Sales**

### Análises disponíveis

- Evolução das vendas por mês;
- Vendas por segmento;
- Vendas por produto;
- Vendas por país;
- Filtros por período;
- Alternância entre diferentes tipos de visualização.

# 🧠 Principais Recursos do Power BI Utilizados

### 📊 Visualização de Dados

Foram utilizados diferentes tipos de gráficos para representar os dados de acordo com cada necessidade analítica:

- Cards;
- Gráfico de área;
- Gráfico de barras;
- Gráfico de rosca;
- Treemap;
- Gráfico de radar;
- Gráfico de colunas.

### 🔎 Segmentadores e Filtros

Utilização de segmentadores para permitir que o usuário explore os dados de acordo com:

- Período;
- Ano;
- País;
- Diferentes dimensões disponíveis na base.

### 🧭 Navegação

Foram implementados botões de navegação para facilitar a movimentação entre as páginas do relatório.

A estrutura foi pensada para que o usuário consiga navegar entre a visão geral de vendas e a análise detalhada de lucro de maneira simples.

### 📈 Interatividade

Os visuais possuem interação entre si, permitindo que a seleção de uma informação influencie os demais elementos do relatório.

# 📚 Base de Dados
O projeto utiliza a base Financials Sample, disponibilizada como parte do desafio da Formação Power BI Analyst.
A base contém informações relacionadas a vendas, produtos, segmentos, países, descontos e resultados financeiros.

# 🚀 Resultado
O resultado é um relatório interativo composto por duas páginas:
Sales Report
Visão geral dos principais indicadores e desempenho de vendas.

Report de Lucro Detalhado

Análise aprofundada da lucratividade por produto, segmento, país e período.

A combinação das duas páginas permite sair de uma visão mais executiva das vendas para uma análise mais detalhada do resultado financeiro.
